# 1. Alec New Research Integration

## Purpose

This document records the integration of Alec's prototype market-intelligence work into the Orange Business Innovation Radar. It is written as a porting guide for another prototype.

The goal is not to claim that Alec's CSV files are official Orange data or perfectly validated. The goal is to reuse valuable student and professional research structure to improve a prototype: cleaner taxonomy, better source provenance, high-precision triage, skewness-aware evidence support, competitor/internal signal space, and visible research gaps.

## Request That Started This Work

The request was to review all files in `Aorangeresearch/Alec2/proto_analysis`, decide what value they provide, integrate useful parts into the scoring system and general ecosystem, keep human research distinct from model-generated material, and document every changed file, methodology, views, and future porting requirement.

The related research themes were:

- Collecting and interpreting use cases as a numerical/evidence component
- Competitor analysis and internal analysis
- Improving statistical analysis when data distributions are skewed
- Finishing a useful prototype on time

## Provenance Policy

Human research is not labelled as AI-generated.

The database preserves:

- `research_origin`: for example `Alec human research prototype` or `radar_pipeline using Alec source metadata`
- `classification_method`: for example `human research` or `human-directed model-assisted pilot`
- `model`: retained only when the source record contains one
- `review_status`: retained as `pending_review` when the source record says so

The taxonomy, source registry, coverage matrix, and research design are treated as Alec's human research/prototype assets. The pilot triage records explicitly contain `gpt-5.6-terra`, so they remain marked as model-assisted and pending review without erasing the human-directed research context.

## Methodology

### 1. Canonical taxonomy

The AI is encouraged to use approved IDs instead of inventing free-text categories.

Example:

```text
private wireless
5G campus network
private 5G
```

map to:

```text
private_5g
```

The model must leave an ID blank instead of guessing when the article does not support it.

### 2. Triage before expensive analysis

Alec's prompt defines a high-precision filter:

```text
raw articles
→ relevant / irrelevant / review
→ taxonomy mapping
→ evidence candidate
→ opportunity grouping
→ scoring
```

The live extraction request now begins with this triage contract and writes one `triage_records` row for every returned article before opportunity storage. This avoids a second API request: triage and structured extraction share the same bounded article batch. The record stores the selected model and `classification_method="model-assisted pipeline triage"`; Alec's original pilot rows retain their separate human-research provenance.

### 3. Evidence strength, not market size

The new indicator is deliberately called `evidence_strength`. It does not claim to estimate market value.

```text
40% log-normalized article volume
+ 35% independent source-group diversity
+ 25% high-value signal mix
```

Article volume uses:

```python
min(log1p(article_count) / log1p(reference_count), 1) * 100
```

This prevents one topic with hundreds of syndicated or repetitive articles from automatically dominating a topic with fewer but more independent sources.

High-value signals currently include:

- Regulation
- Buying signal
- Proof signal

This score is shown beside an opportunity but is separate from attractiveness and right-to-win.

### 4. Source independence

Alec's source registry includes `independence_group`. This is better than counting raw domains alone because several publications may belong to one ownership or syndication family.

The current implementation uses the registry group when available and falls back to the source domain. It remains a prototype prior and should be checked against syndicated content.

### 5. Competitor and internal analysis

The triage schema has fields for `named_` and `actor_role`. These provide a place to capture competitor moves and internal/company actors.

Competitor or internal signals should not automatically increase right-to-win. The current prototype preserves optional `named_organizations` and `actor_role` fields in `triage_records`, so the signal can be reviewed without mixing it into the market score. A dedicated `strategic_signals` table/editor is intentionally left for a later iteration.

They should influence:

- Momentum
- Urgency
- Recommended action
- Partner assessment
- Capability-gap analysis

The market-attractiveness layer should remain separate from company-position analysis.

## What This Should Not Do

- Do not label Alec's human taxonomy and source research as AI-generated.
- Do not treat 30 pilot triage rows as statistically validated market truth.
- Do not call `evidence_strength` market size or financial value.
- Do not let article count dominate independent source diversity.
- Do not mix competitor movement into right-to-win without capability evidence.
- Do not treat vendor content as independent demand evidence automatically.
- Do not treat an empty `evidence_records.csv` as proof that no evidence exists; it is an empty contract.
- Do not expand manufacturing taxonomy to every Orange vertical without a deliberate taxonomy review.
- Do not publish imported triage records as final without reviewing their `review_status`.

6. Use `source_metadata()` when saving evidence.
7. Keep `research_origin`, `classification_method`, `model`, and `review_status` fields.
8. Add the triage page and coverage-gap page.
9. Keep evidence strength separate from market size and attractiveness.
10. Add tests for log normalization, source groups, taxonomy aliases, and provenance.

## Current Prototype Limitations

- Triage and extraction share one API request for cost control. A future larger system can split them into separate agents only if higher precision justifies the additional requests.
- Existing imported triage rows remain pending review.
- Only the current Alec taxonomy is imported; manufacturing is the only approved vertical in that dataset.
- Competitor/internal records use the existing triage fields but have no dedicated editor or separate strategic-signal table yet.
- Source independence cannot fully detect copied/syndicated claims.
- Evidence strength uses configured high-value signal types and simple counts, not statistical causal inference.
